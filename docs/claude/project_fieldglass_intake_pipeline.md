## ⚠️ SITE vs WORK LOCATION — the rule (learned the hard way 2026-07-15)

**Fieldglass "Site"/"Location" is Sodexo's org/BILLING unit. "Work Location" is
where the worker actually reports. They can legitimately disagree — trust
Work Location for the address.** Greg confirmed: posting SDXOJP00184639 says
Site "ADP - SAN DIMAS (0059008001)" but Work Location = 5355 Orangethorpe Dr,
La Palma CA 90623 — "what they are calling ADP San Dimas is actually in La
Palma" (40 mi apart). The bundled directory row for that code also says SAN
DIMAS. HRX's La Palma address is CORRECT; do NOT "fix" it to San Dimas.

**The real bug it contrasts with (Grifols, fixed 2026-07-15):**
ensureSiteCore's `findExistingLocation` tried site code first, then fell back
to a pure NAME match with no address check. FG order SDXOJP00188954 for
GRIFOLS (0037445001 = CLAYTON NC — directory AND Work Location agreed) matched
a hand-created "Grifols" CRM location at Grifols' corporate HQ in Emeryville
CA (`discoveredBy: Manual`, 2025-12-08), then STAMPED the NC site code onto
it — which would have hijacked every future GRIFOLS order and published an NC
job as a Bay Area job (AI copy literally read "hiring a Cook - Grill in
Emeryville, CA"). Caught before harm: 0 SMS, 0 applications.
- Fix (commits 25bf7a4e → refined f40c2563): name fallback now rejects a
  candidate whose **STATE** contradicts the directory. **City is deliberately
  NOT checked** — the ADP case proves a city difference is routinely
  legitimate, and blocking on it would duplicate correct locations. A state
  mismatch has no innocent reading.
- Data repair (.scratch/fixGrifolsSiteMismatch.ts): kept the Emeryville
  location (legit CRM record) minus its wrongly-stamped code; created
  `fgsite_0037445001` (Grifols · Clayton NC, deterministic id → future orders
  hit it by CODE and never reach the name fallback); repointed child account
  `autoLoc_60a97419…`, JO #155, the live posting, and rewrote the AI copy.

**Diagnostic rule:** when directory + Work Location AGREE and HRX differs →
real bug. When directory and Work Location DISAGREE → Work Location wins;
leave it alone. Audit script: .scratch/auditFieldglassSiteMismatches.ts
(read-only; 2026-07-15 run: 327 Sodexo locations, 50 with site codes, 1 real
hijack (Grifols), 1 false positive (ADP), 3 codes newer than the 2026-07-06
directory export — PGA TOUR/SALESFORCE SF TWR/COLORADO MESA — benign, refresh
the export to clear).
